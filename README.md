# Life of Booster

초보자도 실행할 수 있는 Streamlit 기반 습관 관리 MVP입니다.

## 1. Python 설치
Python 3.11 이상을 권장합니다.

## 2. VS Code에서 폴더 열기
이 폴더를 VS Code로 엽니다.

## 3. 가상환경 만들기

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

PowerShell에서 실행 정책 오류가 나면:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

그 다음 다시:

```powershell
.venv\Scripts\Activate.ps1
```

## 4. 패키지 설치

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 5. 실행

```powershell
streamlit run app.py
```

브라우저가 열리면 Life of Booster가 실행됩니다. 종료는 터미널에서 `Ctrl + C`.

가상환경을 활성화하지 않았다면 아래처럼 바로 실행할 수도 있습니다:

```powershell
.venv\Scripts\python.exe -m streamlit run app.py
```

> ⚠️ `python run app.py`, `python app.py`는 동작하지 않습니다.
> Streamlit 앱은 반드시 `streamlit run app.py`로 실행하세요.

## 6. AI 코칭 · 관리자 설정 (선택)

앱은 아무 설정 없이도 실행됩니다.

1. `.env.example`을 복사해서 `.env`로 이름 변경
2. AI 코칭을 쓰려면 `OPENAI_API_KEY`에 본인의 키 입력
   - 앱 안에서 ⚙️ 설정 → 동의 내역 → 'AI 분석을 위한 외부 전송'에도 동의해야 동작해요.
   - 이름·이메일·메모는 보내지 않고 수치 요약만 보냅니다.
3. 관리자 화면을 보려면 `ADMIN_EMAILS`에 관리자 계정 이메일 입력
4. 앱을 끄고 다시 실행

API 키가 들어 있는 `.env`는 GitHub 등에 올리지 마세요.

## 7. 화면 구성 (서비스 흐름도 기준)

| 구역 | 화면 |
|---|---|
| 인증 및 온보딩 | 가입/로그인 → 건강 데이터 동의(거부 시 안내) → 건강 프로필 입력 → 맞춤 시작 계획 |
| 홈 및 목표 관리 | 홈(연속 달성 · 목표 진행률 · 맞춤 추천 수락/거절 · 오늘의 미션) · 목표 설정 · 알림함 |
| 생활 데이터 기록 | 수면 기록 · 운동(계획 → 실천 가이드 → 기록 → 보상/차감 안내) · 식단(끼니별 계획 · 식사 기록 · 물) · 기기 연동 · 최근 7일 기록 고치기/지우기 |
| 게임화 및 보상 | 레벨 · 경험치 · 포인트 · 배지 · 누적 보상 이력 · 포인트 상점(유예권, 체험권) |
| 카메라 챌린지 | 푸시업·스쿼트 개수 자동 인식 · 주간 랭킹(1위 보상) · 도전장 대결 |
| 순위표 | 사용자끼리 겨루는 순위 (이번 주 · 이번 달 · 전체 기간 / 종합 누적 개수 · 종목별 최고 기록) · 시상대 · 내 순위 강조 |
| 주간 리포트 | 기본 리포트(무료) · 심화 리포트(유료) |
| 구독 및 결제 | 구독 안내 → 결제 → 성공/실패 안내 · 구독 관리/해지 |
| 설정 | 알림 · 프로필 수정 · 동의 내역/철회 · 차감 규칙 · 계정 |
| 관리자 | 주간 활성 사용자, 재방문율, 목표 달성률, 리포트 확인율, 구독 전환율 등 |

## 8. 시연용으로 만든 부분

아래 기능은 실제 서비스와 연결하지 않고 흉내만 냅니다.

- **결제**: 실제로 돈이 나가지 않고 카드 정보도 받지 않습니다. 가격도 예시입니다.
- **알림**: 휴대폰 알림 대신, 알림 시각이 지나면 홈 화면 위에 안내가 뜹니다.
- **기기 연동**: 실제 기기 대신 날짜마다 정해진 가짜 걸음 수를 가져옵니다.
- **로그인 유지**: 브라우저를 새로고침하면 다시 로그인해야 합니다.

## 9. 카메라 챌린지 사용법

1. 왼쪽 메뉴 → 📸 카메라 챌린지
2. 종목(푸시업/스쿼트)과 시간(30초/60초)을 고르고 「📷 카메라 켜기」
3. 브라우저가 카메라 허용을 물으면 「허용」
4. 화면 안내대로 몸 전체가 보이게 자리를 잡고 「▶️ 시작」 → 3초 뒤 시작

- 영상은 저장하거나 보내지 않고, 내 컴퓨터 브라우저 안에서만 분석합니다. 저장되는 건 개수뿐입니다.
- 자세 인식 도구(구글 MediaPipe)를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
- 스쿼트: 무릎이 충분히 굽혀졌다가 펴져야 1회로 셉니다.
- 푸시업: 엎드린 자세가 옆에서 보여야 하고, 팔꿈치가 충분히 굽혀졌다가 펴져야 1회로 셉니다.
- 카메라는 `localhost` 주소에서만 켜집니다. 다른 컴퓨터에서 접속하려면 https 주소가 필요합니다.

## 10. 파일 구조

- app.py: 앱 전체 (화면 + 데이터 처리 + 추천)
- life_of_booster.db: 실행하면 자동으로 만들어지는 데이터 파일
- requirements.txt: 필요한 파이썬 패키지
- .env: API 키 등 비밀 설정
